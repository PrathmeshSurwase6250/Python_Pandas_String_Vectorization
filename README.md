# Python Pandas: String Vectorization and Pivot Tables

This repository contains hands-on practice with Pandas string operations, string vectorization, pivot tables, and data manipulation using Python.

## 📚 Topics Covered

- Pandas String Methods (`.str`)
- String Vectorization
- DataFrame Reshaping
- Pivot and Pivot Tables
- Data Aggregation using `sum()`, `mean()`, and other functions
- Handling Missing Values
- CSV Data Analysis
- Data Visualization using Matplotlib

## 📂 Repository Contents

| File | Description |
|---|---|
| `vertorizedString.ipynb` | Practice notebook for Pandas string vectorization |
| `pivot.ipynb` | Practice notebook for pivot tables and data reshaping |
| `expense_data.csv` | Expense dataset for analysis and pivot-table practice |
| `titanic.csv` | Titanic dataset for data analysis practice |

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
